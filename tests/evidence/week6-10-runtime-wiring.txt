Browser-runner unblock
- Initial executable-regression navigation failed before document load: Page.navigate returned net::ERR_NAME_NOT_RESOLVED, the document was chrome-error://chromewebdata/, candidate requests were zero, and no dialog or auth code had run.
- Cause: the runner's `--host-resolver-rules=MAP * ~NOTFOUND` also NXDOMAINed 127.0.0.1.
- Fix: retain the launch-time deny proxy and use the supported comma form with explicit exclusions: `MAP,*~NOTFOUND,EXCLUDE,127.0.0.1,EXCLUDE,localhost`.
