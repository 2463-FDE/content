## Claims and first-party evidence

- Replicated partitions can move leadership after eligible broker failure; consumer membership/metadata changes can pause work and cause assignment movement — [Apache Kafka replication design](https://kafka.apache.org/documentation/#replication) and [operations](https://kafka.apache.org/documentation/#operations).
- Messaging traces cross asynchronous producer/consumer boundaries and use messaging spans and propagation carriers — [OpenTelemetry messaging semantic conventions](https://opentelemetry.io/docs/specs/semconv/messaging/messaging-spans/).
- W3C Trace Context defines `traceparent`/`tracestate` propagation; Kafka record headers are the carrier in this design — [W3C Trace Context](https://www.w3.org/TR/trace-context/).
- Google Workload Identity Federation exchanges external workload identity for short-lived access without service-account keys — [Google Cloud Workload Identity Federation](https://cloud.google.com/iam/docs/workload-identity-federation).
- Private Service Connect is Google's service-oriented private connectivity model; whether it fits a specific managed Kafka path requires a dated availability review — [Google Cloud Private Service Connect](https://cloud.google.com/vpc/docs/private-service-connect).
- AWS and Google publish direction-, region-, and service-sensitive network pricing; a cross-cloud total must preserve those categories and retrieval date — [AWS data transfer](https://aws.amazon.com/ec2/pricing/on-demand/#Data_Transfer) and [Google Cloud network pricing](https://cloud.google.com/vpc/network-pricing).
