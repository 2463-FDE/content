## Professional Agentic Architect (beta)

- Page: https://cloud.google.com/learn/certification/agentic-architect/
- Guide: https://services.google.com/fh/files/misc/professional_agentic_architect_exam_guide_english.pdf
- Learning path: https://www.skills.google/paths/4525 ("will be updated when the certification exam becomes Generally Available (GA) in November")
- Status: **Beta**. "Professional Agentic Architect GA exam will launch in mid-November"; "GA registration opens Nov 2". Beta: 3 hours, ~80 multiple-choice, $120 (40% off $200), English, validity 1 year, no prerequisites; recommended "3+ years of hands-on experience building, testing, deploying, and managing cloud solutions including 1+ years building agentic solutions using Google Cloud". Two parts: proctored exam, then PAA hands-on labs in Google Skills.

| Section | Weight | Subsections |
|---|---|---|
| 1 Building agents using low-code tools | ~13% | 1.1 Configuring agentic workflows and behavior using low-code tools · 1.2 Connecting enterprise data to Gemini Enterprise |
| 2 Using coding agents for application development | ~17% | 2.1 Using coding agents effectively · 2.2 Customizing coding agents for enterprise workflows |
| 3 Developing custom agents | ~33% | 3.1 Designing and building agentic workflows in code · 3.2 Integrating enterprise domain knowledge · 3.3 Orchestrating and coordinating agentic workflows |
| 4 Evaluating and deploying agentic workflows | ~22% | 4.1 Evaluating agents in development and in production · 4.2 Deploying and scaling production workloads |
| 5 Securing and governing agentic workflows | ~15% | 5.1 Configuring agent security and governance · 5.2 Implementing secure agent behavior and execution |

Named tools (guide, verbatim names): Agent Development Kit (ADK); Agent evaluation; Agent Gateway; Agent Identity; Agent Registry; Agent Retrieval and Vector Search 1.0; Agent Runtime (formerly Agent Engine); Agent Search (formerly Vertex AI Search); Agent2Agent (A2A), MCP; Agents CLI in Agent Platform; Antigravity (CLI, SDK, App); Auth Manager (OAuth 2.0); BigQuery; Cloud Run; Cloud SQL; Cloud Storage; Firestore; Gemini Enterprise; Gemini LLMs; Google Cloud Observability (Cloud Logging and Cloud Trace); GKE; Memorystore for Redis; Model Armor; MCP servers; Model Garden; RAG Engine; Sensitive Data Protection; Skill Registry. Section 2.1 names "Antigravity and Claude Code on Google Cloud".

## Professional Machine Learning Engineer

- Page: https://cloud.google.com/learn/certification/machine-learning-engineer
- Guide: https://services.google.com/fh/files/misc/professional_machine_learning_engineer_exam_guide_english_new.pdf
- Learning path: https://www.skills.google/paths/17
- Status: GA; "This exam was updated to reflect the transition from Vertex AI to Gemini Enterprise Agent Platform, updates to Google Cloud's data and analytics stack". Two hours; 50–60 multiple choice / multiple select; $200; English, Japanese; "The exam does not directly assess coding skill."
