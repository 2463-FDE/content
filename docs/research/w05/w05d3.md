## Verified claims

1. The Neo4j GraphRAG Python package documents knowledge-graph construction and retrieval components.
2. `SimpleKGPipeline` is currently under `neo4j_graphrag.experimental.pipeline.kg_builder`. The `experimental` namespace is a compatibility warning: pin and test versions, and do not portray the API as stable.
3. LLM extraction produces candidate entities and relationships; it is not authoritative truth. A defensible pipeline preserves source identifiers/provenance and validates output against an allowed schema before merge.
4. `VectorRetriever` retrieves indexed entities by embedding similarity. `VectorCypherRetriever` uses vector search and then a developer-supplied Cypher traversal to enrich the result. `Text2CypherRetriever` uses a model to generate Cypher from natural language and therefore requires schema context, read-only scope, validation, and evaluation.
5. GraphRAG does not make an answer grounded by itself. Grounding depends on retrieval quality, provenance, context assembly, and answer checks.
