## Exit-cost statements

Source: https://aws.amazon.com/blogs/aws/free-data-transfer-out-to-internet-when-moving-out-of-aws/

- AWS describes free data transfer out when a customer moves data out of AWS and discontinues use, subject to support review and service-specific migration planning. This is not a claim that ordinary operating egress is free.

Source: https://cloud.google.com/blog/products/networking/eliminating-data-transfer-fees-when-migrating-off-google-cloud

- Google describes waiving data-transfer fees for eligible customers moving data out of Google Cloud and terminating the agreement, subject to the documented request/approval process and timing. This is not a claim that ordinary operating egress is free.

## Defense rule

Inventory portable artifacts, provider-native dependencies, data volume, export format, transfer path, ordinary egress exposure, waiver eligibility/approval assumptions, remaining service/operations cost, recovery validation, owner, and time. A waiver can reduce one network charge; it does not erase migration labor, dual run, service termination conditions, data conversion, downtime, or residual copies. State the conditions that flip the recommendation and the evidence still missing.
