## Arithmetic and caching contract

- At Sonnet 5.5's $2/$10 rate, 4,800 input plus 400 output tokens cost $0.0136 per call; 50,000 calls cost $680/day; 1,200 input-history tokens across that volume cost $120/day.
- At the same rate, 5,800 input plus 400 output tokens cost $0.0156 per call and $624/day at 40,000 calls.
- Anthropic documents 5-minute cache writes at 1.25× input, one-hour writes at 2×, Sonnet 5.5 and Opus 5.5 reads at 0.05×, Fable 5.1 reads at 0.025×, and a standard 0.1× read multiplier for models without an exception. — [Anthropic Prompt caching](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)
- For the 5,800/400 example, caching a 4,500-token prefix at Sonnet 5.5's 0.05× read rate yields a steady-state cost of $0.00705 (displayed as $0.0071) and saves $342/day after display rounding at 40,000 calls. Ten prefix uses cost 1.70 prefix-equivalents (1.25 + 9×0.05), an 83% reduction from 10 uncached equivalents.
- The shared widget defaults to 4,800 input, 400 output, $2/$10, and 50,000 calls/day. It publishes raw numeric values separately from locale-formatted visible currency so regression arithmetic never parses locale-dependent punctuation.

## Bedrock endpoint and routing note

- The current AWS Haiku 5.5 and Sonnet 5.5 model cards list `us.anthropic.claude-haiku-5-5` and `us.anthropic.claude-sonnet-5-5` as US geo inference-profile IDs for `bedrock-runtime`; geo profiles may route across Regions in that geography and must not be described as single-Region routing.
- The same `bedrock-runtime` tables list bare in-Region model IDs where regional availability allows, and `global.` profiles for global cross-Region routing. The separate `bedrock-mantle` endpoint also uses bare IDs. An ID therefore has to be interpreted with its endpoint, Region, and profile type.
- Static curriculum cannot infer an organization's enabled or approved model/profile. Trainers and implementation teams must check the current model card and organization policy and must not guess a prefix. — [AWS Claude Haiku 5.5 model card](https://docs.aws.amazon.com/bedrock/latest/userguide/model-card-anthropic-claude-haiku-5-5.html), [AWS Claude Sonnet 5.5 model card](https://docs.aws.amazon.com/bedrock/latest/userguide/model-card-anthropic-claude-sonnet-5-5.html), and [AWS Cross-Region inference](https://docs.aws.amazon.com/bedrock/latest/userguide/cross-region-inference.html)

## Still-valid production claims retained

- A context window is the request's token budget and applications can count tokens before sending. — [Anthropic Context windows](https://platform.claude.com/docs/en/build-with-claude/context-windows) and [Token counting](https://platform.claude.com/docs/en/build-with-claude/token-counting)
- Prompt caching depends on matching stable prefixes; volatile content belongs after the cache boundary. — [Anthropic Prompt caching](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)
- Streaming can fail after an initial successful response; batch results are asynchronous, keyed by `custom_id`, and currently priced at a 50% discount. — [Anthropic Streaming](https://platform.claude.com/docs/en/build-with-claude/streaming), [Message Batches](https://platform.claude.com/docs/en/build-with-claude/batch-processing), and [API errors](https://platform.claude.com/docs/en/api/errors)
- Exponential backoff with jitter spreads synchronized retries. — [AWS Architecture Blog](https://aws.amazon.com/blogs/architecture/exponential-backoff-and-jitter/)
