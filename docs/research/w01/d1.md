## Claims (each MUST carry a source)

- A Claude context window is the total token budget available to a request; input and generated output both consume that budget. — [Anthropic — Context windows](https://platform.claude.com/docs/en/build-with-claude/context-windows)
- Applications can count message tokens before sending a request, so a request builder can enforce a budget rather than estimate from word count. — [Anthropic — Token counting](https://platform.claude.com/docs/en/build-with-claude/token-counting)
- Transformer models generate representations using attention rather than recurrence; the original architecture is the conceptual source for the lesson's attention framing. — [Vaswani et al. — Attention Is All You Need](https://arxiv.org/abs/1706.03762)
- Claude Sonnet 5 is priced at $2 per million input tokens and $10 per million output tokens. At those rates, 4,800 input tokens plus 400 output tokens cost $0.0136 per call; 50,000 calls cost $680/day, and 1,200 avoidable input tokens across that volume cost $120/day. — [Anthropic — Models overview](https://platform.claude.com/docs/en/models/overview)
- For `bedrock-runtime` in `us-east-1`, AWS lists `us.anthropic.claude-haiku-4-5-20251001-v1:0` as the US geo inference-profile ID for Claude Haiku 4.5. — [AWS — Claude Haiku 4.5 model card](https://docs.aws.amazon.com/bedrock/latest/userguide/model-card-anthropic-claude-haiku-4-5.html)
